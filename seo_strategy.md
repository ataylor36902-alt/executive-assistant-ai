# SEO Strategy

## In scope
- Public ClassScribe web entry page, any source-visible public marketing/help/privacy content, and publicly accessible instructor entry page.

## Out of scope
- Private sync-code libraries, courses, notes, lecture recordings, authenticated instructor workspaces, API routes, native mobile app, and design sandbox.

## Target audience
- Students seeking lecture transcription, organized notes, and study tools; educators evaluating ClassScribe EDU.

## Primary keywords
- Lecture transcription, AI lecture notes, student study tools; refine with product team when known.

## Crawler assumptions
- Analyze the deployed web artifact served from `artifacts/classscribe/web-public/`; the Vite `src/` shell is not the configured web entry point. Source-only; no live request assumptions.
